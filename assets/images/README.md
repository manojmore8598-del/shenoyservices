# Image Assets

Place genuine business images only. Do not add fabricated certificates or unrelated stock photos.

## Folders

| Folder | Use |
|--------|-----|
| `logo/` | Brand logo (preserve aspect ratio) |
| `office/` | Storefront / interior photos (add when available) |
| `certificates/` | Official certificates |
| `awards/` | Award ceremony photographs |
| `gallery/` | Optional copies or additional gallery images |

## Guidelines

- Use descriptive filenames in lowercase with hyphens.
- Keep certificate images readable; avoid heavy compression.
- Reference images with relative paths such as `assets/images/logo/shenoy-services-logo.jpg`.
- For logos and certificates in galleries, prefer `object-fit: contain`.
